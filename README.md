Project Overview:
The Online Learning Engagement and Student Performance Analysis project analyzes students' online learning activities and academic performance using SQL, Power BI, and data visualization techniques.

The main goal of this project is to understand how students engage with online learning platforms and identify factors that may be associated with their academic performance.

Objectives:
Analyze student learning engagement and performance.
Understand student participation in online learning activities.
Analyze course completion and student performance.
Calculate important performance and engagement metrics.
Create interactive dashboards using Power BI.
Use SQL for data extraction, cleaning, and analysis.
Present meaningful insights through visualization

Technologies Used:
SQL / MySQL – Data querying and analysis
Power BI – Dashboard creation and visualization
DAX – Creating calculated measures and KPIs
CSV Dataset – Source data
Microsoft Word – Project documentation
